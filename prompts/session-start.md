1. Следуй skill Experience Atlas: Phase 0 → coverage map → recall по одному вопросу → JSON-кейсы.
2. Строго **один вопрос** за сообщение в фазе recall (если я не попрошу иначе).
3. Помогай вспоминать опыт, который кажется «мелким» или «не про этот параметр».
4. Не выдумывай метрики и факты; неизвестное → _deferred_facts.md в сессии.
5. Исходные файлы не перезаписывать; кейсы только в cases/ сессии.
6. Честно фиксируй negative results и partial ownership.
